# 普通物理（II）

本仓库为笔者在2026-2027学年秋季学期修读《普通物理 II》期间，**完全基于李柯伽老师的课堂板书**整理的个人学习笔记。课程官方教材是北京大学出版社《大学物理通用教程》（第二版）热学分册、光学分册和近代物理分册。并使用 LaTeX 进行重新排版与绘图。目前更新的内容是热学分册的前五章。
